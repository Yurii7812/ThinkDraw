# 自分で決めたこと(SPEC の第 11・12 章に無い細部)

SPEC の前書きに従い、仮置きにも未決にも書かれていない細部で、実装のときに決めたことを 1 行ずつ残す。

## 技術

- 画面の UI フレームワークは使わず、素の DOM + TypeScript。理由: 画面の部品が少なく(キャンバス・ポップアップ・検索・グラフ)、キャンバスは座標を直接扱うため、仮想 DOM の利点が小さい。依存も減らせる。
- 本文エディタは ProseMirror + prosemirror-markdown(CommonMark)。`[文章](ID.md)` のリンクと `![](assets/…)` の画像が往復で変わらないことを単体の試験で確かめた(`test/markdown.test.ts`)。
- グラフの層状レイアウトは `@dagrejs/dagre`。理由: 同期で動き、入力の順を固定すれば結果が決定論的。elkjs より軽い。
- まとめるのは esbuild。単体の試験は vitest、画面の試験は Playwright の Electron 起動(xvfb-run の上)。
- frontmatter を読むのは `yaml` ライブラリ、書くのは自前(SPEC の例と同じ「1 行 1 項目・members と links は流れ形式」にそろえるため)。素で書くと値が変わる文字列だけ引用符で囲む。
- 知らない frontmatter のキー(外部のエディタで足されたもの)は、書き戻すときに残す。
- frontmatter の `id` とファイル名が食い違ったら、ファイル名を正とする(リンクはファイル名で張られるため)。
- ファイル名が ID の形(小文字英数字 10 文字)でない `.md` は、ThinkDraw のノードとして扱わない(`root.md` は除く)。frontmatter の無い `.md`(ID の名前のもの)は `note` として読む。
- 自動保存は、変更から 300ms 後にまとめて書く。窓を閉じるときは、画面に残っている変更を書き終えてから閉じる。
- ファイル監視は Node の `fs.watch`(フォルダ直下のみ。ノードはすべて直下にあるため)。自分で書いた中身と同じ通知は無視する。

## データの意味

- `members` の `x, y` は、ノードの左上の座標。
- 線を引く操作(ドラッグ・Tab・Enter)で作る線の種類は `line`(線)。
- ノードを削除しても、ほかのノードからそのノードへの線(`links`)はファイルに残す(描かない)。ゴミ箱から手で戻したときに線も戻るように。
- 根(ホーム)にしか入っていないノードを「ホームから外す」は、何もしない(知らせを出す)。
- 読み込み時・外部変更の後に、どこにも属さないノードを見つけたら、根の下のほうに 6 列で並べて入れる。
- 元に戻す(Ctrl+Z)は、キャンバスと所属の操作だけ。本文の書き換えはポップアップのエディタの履歴(エディタの中の Ctrl+Z)に任せ、キャンバスの Ctrl+Z では本文を巻き戻さない。履歴は 300 歩まで。
- 外部のエディタの変更を取り込んだら、元に戻すの履歴は捨てる(古い写しで外の変更を上書きしないため)。
- `updated` は、そのノードのファイルの中身が変わるたびに更新する(グループの中の位置が変わると、グループの `updated` が変わる)。
- スプレッドで置いたカードの frontmatter の `spread:` に、SPEC 3.2 の `run`・`pos` のほかに `spread`(スプレッドの ID)を足した。位置の名前とヒントを引くのに必要なため。**SPEC の形への追加なので、報告に書く。**
- カードの `title` には、カードの日本語名を入れる(検索で見つかるように)。

## 操作

- 右ドラッグでノードを**グループの上**に重ねて離すと、そのグループへ**移す**(今のグループからは外れる)。SPEC 3.6 の「入れる」(元の所属を残す)は、右クリックの「別のグループにも入れる…」で行う。
- 右ドラッグでノードを**普通のノードの上**に重ねると、その 2 つ(選択していれば選択全部)を束ね、重ねた先の位置にグループを置く(SPEC 4.2 のとおり)。
- 束ねた直後は、グループの名前をその場で書ける状態にする(Esc で空のまま確定)。
- グループの 1 回クリックは「選ぶ」だけ(ダブルクリックで開く)。名前は右クリックの「名前を変える」か、上部バーの題を押して開くポップアップで変える。
- `note` と `card` は 1 回クリックで本文のポップアップを開く。`text` は 1 回クリックで文字を直し、本文は右クリックの「本文を開く」か、本文ありの印(¶)を押して開く。
- 空きを左クリックしたとき、文字を書いている途中なら、まず確定するだけ(新しい文字は始めない)。
- Enter で作る次のノードは、すぐ下の空いている所に置く。Tab で作る子は右に置き、すでに右に子があれば、その一番下の下に置く。
- 選択したものに Enter を押すと、グループなら開き、それ以外はクリックと同じ。
- 本文の中のリンクは、押すと小さな吹き出し(「→ 題」)を出し、それを押すとそこへ移る(書いている最中の誤操作を避けるため)。外部の URL は外部のブラウザで開く。
- 本文で文章を選ばずに Ctrl+K を押すと、普通の検索になる。リンク先の窓には、`http(s)://…` を打つと URL へのリンクも選べる。
- 検索は、空白で区切った語をすべて含むもの(題と本文の部分一致、大文字小文字を区別しない)。題に当たるものを先に出す。
- 検索で選んだものがグループなら、そのグループを開く。それ以外は、今のグループにあればそこ、無ければ親(根を優先、次に ID の順で最初の親)を開いて、中心に寄せて光らせる。
- ショートカット(Ctrl のみの決まりの中で): 戻る Ctrl+[、進む Ctrl+]、ホーム Ctrl+Home、グラフの開閉 Ctrl+E、ショートカットの一覧 Ctrl+/。マウスの戻る・進むボタンも使える。Delete と Backspace はどちらもゴミ箱へ。
- 「引く」の直後、置いたカードが画面に収まらなければ、中心を保ったまま縮める。
- 逆位置を入れる設定がオンのとき、各カードは 1/2 の確率で逆位置(暗号論的な乱数)。

## 見た目

- プリセットの色は 8 色(赤・橙・黄・緑・青緑・青・紫・桃)。ライトとダークで別の濃さを用意。文字ノードは文字の色、ノートとグループは左の帯、カードは枠の色に使う。
- グループの開閉のアニメーションは、0.2 秒のフェード(拡大・縮小の動きは付けていない)。
- カードの大きさは幅 110px(画像の比 360:600)。スプレッドの座標は「カードの幅 ÷ 定義のカードの幅」で縮める。自由に引くときは 1 段に最大 7 枚。
- グラフのグループ表示では、段を決めるのは所属の線だけ。グループ同士のリンクは配置に使わず、後から直線で描く。ノード表示では本文のリンクも「線」として描く。
- グラフの配置は `.thinkdraw/graph-layout.json` に、表示ごとに保存する(ノード表示は直近 20 グループぶん)。構造のハッシュ(ID・種類・題・線)が変わったときだけ計算し直す。
- グラフの丸の文字の幅は、フォントで測らず文字数から推定する(配置を画面のフォントに依存させず、決定論的にするため)。題は 14 文字で切る。
- 「ノート」の丸は点線の枠、グループは角の小さい箱、それ以外は丸みの強い箱で区別する。

## 設定・保存場所

- 最後に開いたフォルダ・テーマ・逆位置の設定は、アプリの設定(`~/.config/thinkdraw/config.json`。Electron の userData)に置く。フォルダごとの `.thinkdraw/` には置かない。
- 画像を貼ると `assets/<年月日>-<ランダム 8 桁>.<拡張子>` に保存する。
- URL の題は、`og:title` か `<title>` を取る。6 秒で諦め、取れなければ URL をそのまま出す。キャッシュは `.thinkdraw/url-cache.json`。リンクカードを押すと外部のブラウザで開く。
- 試験のため、環境変数 `THINKDRAW_VAULT`(開くフォルダ)と `THINKDRAW_USERDATA`(設定の置き場)で場所を差し替えられる。

## そのうえで自分で決めたこと

- グループの frontmatter に `refs:`(引用。`members` と同じ形)と `strokes:`(ペンの線)を足した。**SPEC 3.2 の形への追加。** 易のカードは `card:` に `moving:`(変わる爻。0 = 初爻)を足した。
- 引用は、元のノードを削除すると消える。引用しか残っていないノード(所属をすべて失ったもの)は根に入る(引用は所属に数えない)。グループは自分の祖先も引用できる(入れ子ではないので循環にならない)。同じグループに、所属と引用の両方では置かない。
- 引用をグループの上に右ドラッグで重ねると、引用のまま移る。束ねると、引用は新しいグループの中でも引用のまま。解くと、親へ引用として移る。
- 引用の右クリックのメニューは「所属しているグループへ」「引用を外す」。所属のものは「別のグループにも入れる…」「別のグループに引用する…」「このグループから外す」。
- Ctrl+L(キャンバス): 1 つ選んでいれば、検索して選んだものと線でつなぐ。相手がこのキャンバスに無ければ、選んだもののそばに引用として置いてから線を引く。何も選んでいなければ、画面の真ん中に引用として置く(すでにあれば、そこへ寄せる)。
- Ctrl+L(本文): 文章を選んでいればそれをリンクに、選んでいなければ、カーソルの所に `[題](ID.md)` を入れる。本文の中の Ctrl+K は普通の検索。
- 空きのクリックは、何かを選んでいても、選択を外してそのまま書き始める(2 回押さなくてよいように)。
- 「開く」: 文字は書き直し、グループは中へ、ノートは大画面、カードは本文のポップアップ(メモ用)。**カードを 1 つ選んだときだけ**右の欄を自動で開き、「詳細」に切り替える(文字では開かない。2026-11-22 の夜に変更)。
- カードの本文の初期の見出し(この位置での読み・自分の解釈)は入れないことにした(上の利用者の答えから)。
- 右の欄の「この位置での読み」は、新しい文を書かず、位置の名前とヒント + カードの向きの説明を組み合わせて 1 文にしている。下に反対の向きの説明も小さく出す。
- Tab・Enter の置き場所(`core/placement.ts`): 親の箱のまわりに、少し横長の輪を 24 方向に取り、一番内側の輪から順に、ほかとの隙間が 36px 以上ある方向を探す。その輪の中で、一番空いている方向の 8 割以上の空き具合の方向から、ランダムに 1 つ。Enter は同じ親のまわり(親がいなければ、今のノードのまわり)。
- まとめて置くもの(スプレッド・易・発想カードの全部並べる)は、すでにあるものと重なるなら、40px 刻みで一番近い空いた所へまとめてずらす。
- 問いを書いて引いたとき、問いの文字からすべてのカードへ線を引く(ケルト十字では線が 10 本になる。見づらければ直す)。
- 易: コインを 3 枚 × 6 回(表 3・裏 2 の合計で 6〜9)。6・9 が変わる爻。本卦と之卦を横に並べ、本卦から之卦へ矢印。変わる爻が無ければ本卦だけ。
- 発想カード: 7 種類(5W1H・SCAMPER・6 つの視点・立場を変える・次の一歩・問い・ランダムな言葉)。「全部並べる」には、枚数の多い「問い」と「ランダムな言葉」は出さない。「1 枚」は、選んでいるものがあれば、そのそばに置いてつなぐ。
- 乱数の元は「おまかせ(暗号乱数)」「言葉から(同じ言葉なら同じ結果。空なら問いの文)」「時刻」の 3 つ。YuriiNote にあった「マウスでかき混ぜる」は入れていない。
- 逆位置は、入れる設定のとき 1/2 の確率。
- ペン: 太さは 細 2・中 4・太 8 と、つまみで 1〜30。蛍光ペンは太さ 3 倍(最低 8)で半透明。消しゴムは、触れた線を丸ごと消す。ペンモード中は、ノードの上でも描ける。ペンの設定(色・太さ・道具)はアプリの設定に覚える。
- 引く設定・最後に使った引き方は、アプリの設定に覚える。「引く」ボタンは、最後に使った引き方をもう一度。
- グラフの「この辺り」(`buildLocalGraph`): 今のグループ・その親・子のグループ・引用し合うもの・線でつながるもの・中の物から外へのリンクの先(とその所属先)・選んでいるノードとその所属先と引用先。60 個まで。
- カードにカーソルを合わせたときの小さな窓は、タロットと易で残した(右の欄と同じ内容の短い版)。

- 左右のタブ(修正14 の作り直し。利用者「Obsidian みたいにタブをドラッグする感じ」): ノートもボードもタブ。ノートを開くと、ノートの名前のタブ(📄)ができて大画面で出る(Esc・× でそのタブを閉じて、開いた元のタブへ)。分けていないときは上に 1 列(1 枚なら出さない)。タブを左の画面の右半分へドラッグすると左右に分かれ、左右それぞれの見出しにタブの列が出る(↑・タブ・＋、右は分割をやめる ×)。タブは列の中で並べ替え・反対側の列や画面へドラッグで移せる。左の最後の 1 枚を右へ出すときは左にも残す。右のタブが無くなったら分割は戻る。分けられるのは左右の 2 つまで。Ctrl+\ = 今のタブを反対側へ(前の「右に出すグループを選ぶ」はやめた)。Ctrl+W・Ctrl+Tab は今使っている側。右のタブも覚えて、次に開いたときに戻す(前の版の「横のグループ」は右のタブ 1 枚にする)。
